# v1.6 검증 기록

Playwright Chromium, 가짜 카메라, 모의 서버로 확인했습니다. 테스트용 임시 그림으로 확인했습니다. 내장 실루엣은 완성도가 낮아 뺐고, 지금은 PNG를 넣은 인물만 나타납니다.

- 통과: 첫 화면에 '인물 없이 + 박준채·박기옥·이광춘·장재성' 다섯 버튼 표시, 기본 선택은 '인물 없이'
- 통과: 박준채 선택 → 촬영 화면 오른쪽에 실루엣과 "박준채 · 광주고보 2학년" 안내 표시
- 통과: 네 컷 모두 미리보기와 같은 위치에 실루엣 합성, 첫 컷에 이름표, 하단 "박준채와 함께한 역사네컷"
- 통과: 결과 화면에서 박기옥으로 변경 → 기기 보관 기록 갱신(원본은 JPG로 보관)
- 통과: 디자인 변경 후 접수 → `characterId:'park-gi-ok'`, `characterLabel:'박기옥'` 전송 → 완료 화면 "2번 부스 · 기억 노트 · 박기옥"
- 통과: 서버를 고치기 전 상황(CHARACTER_ID 거절) → 1회 만에 중단, 사진 기기 보관, 재전송 버튼과 안내 표시
- 통과: 다음 팀으로 넘어가면 '인물 없이'로 초기화
- 통과: 폰 폭(390px) 가로 넘침 없음, JavaScript 오류 없음

확인하지 못한 것: 실제 크롬북, 실제 Apps Script 서버, 구글 폰트를 받은 상태의 글꼴(테스트 환경에서 폰트 서버 접속이 막힘).
