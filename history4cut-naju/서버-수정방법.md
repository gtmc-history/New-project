# 서버(Apps Script) 수정 방법

Code.gs v2.3에서 **`CONFIG.CHARACTERS` 블록만** 바꾸면 됩니다. 관리자 코드나 이메일 등 다른 부분은 그대로 둡니다.

## 1. 이 부분을 찾아서

```js
  CHARACTERS: Object.freeze({
    'kim-gu': '김구',
    'yu-gwansun': '유관순',
    'an-jung-geun': '안중근',
    'none': '인물 없음'
  }),
```

## 2. 이렇게 바꿉니다

```js
  CHARACTERS: Object.freeze({
    'park-jun-chae': '박준채',
    'park-gi-ok': '박기옥',
    'lee-gwang-chun': '이광춘',
    'jang-jae-seong': '장재성',
    // 예전 촬영 페이지에서 보관해 둔 사진도 재전송할 수 있도록 남겨 둡니다.
    'kim-gu': '김구',
    'yu-gwansun': '유관순',
    'an-jung-geun': '안중근',
    'none': '인물 없음'
  }),
```

## 3. 새 버전으로 배포

Apps Script 편집기 → **배포 → 배포 관리** → 업로드용 배포의 연필(수정) → 버전: **새 버전** → 배포.

'새 배포'를 누르면 주소가 바뀌니 꼭 **기존 배포 수정**으로 합니다. 주소가 바뀌면 촬영 페이지의 `GAS_URL`도 바꿔야 하고, 기존 보관 사진은 자동 재전송되지 않습니다.

관리자 배포를 따로 쓰고 있다면 같은 방법으로 함께 새 버전으로 올립니다. 관리자 화면의 '역사 인물' 칸은 서버가 이 목록에서 이름을 가져와 기록합니다.

## 확인

인물 하나를 골라 촬영하고 접수합니다. 완료 화면이 뜨면 서버 반영이 끝난 것입니다. 거절되면 배포가 '새 버전'으로 되었는지 확인하세요.
