# 역사네컷 · 나주역 1929 (v1.7)

학생독립운동기념일(학생의 날) 행사용 네 컷 촬영 부스입니다. 이 폴더 안에 필요한 것이 모두 있습니다.

```
history4cut-naju/
├─ README.md            ← 지금 이 파일 (먼저 읽기)
├─ site/                ← 이 폴더를 통째로 촬영 사이트(HTTPS)에 올립니다
│  ├─ index.html        ← 촬영 페이지
│  └─ assets/characters/← 인물 그림 PNG 넣는 곳 (아직 비어 있음)
├─ 인물그림-만들기.md     ← 인물 그림 규격과 생성 프롬프트
├─ 서버-수정방법.md       ← Apps Script Code.gs에서 고칠 부분
├─ 검증기록.md           ← v1.7 테스트 결과
├─ v1.4-운영안내.md       ← 사진 보관·재전송 등 운영 방법 (그대로 유효)
└─ 검증기록-v1.4.md       ← v1.4 테스트 결과
```

## 배포 순서 (꼭 이 순서로)

1. **서버 먼저**: `서버-수정방법.md`대로 Code.gs의 인물 목록을 고치고 새 버전으로 배포합니다. 기존 배포를 수정하면 주소는 바뀌지 않습니다.
2. **촬영 페이지**: `site/` 폴더를 기존 촬영 사이트의 같은 주소에 교체해 올립니다.
3. **(선택) 인물 그림**: `인물그림-만들기.md`대로 만든 PNG를 `site/assets/characters/`에 넣으면 인물 스티커가 생깁니다. 없어도 촬영·미션·스티커는 모두 동작합니다.
4. **확인**: 크롬북에서 한 장 찍어 스티커를 붙이고 접수한 뒤, 관리자 화면에서 사진에 스티커가 들어갔는지 봅니다.

서버를 고치지 않아도 인물 스티커를 쓰지 않은 사진은 그대로 접수됩니다. 인물 스티커를 붙인 사진만 서버 수정이 필요합니다. 서버를 고치기 전에 접수하면 사진은 기기에 보관되고 "서버에 이 역사 인물이 등록되어 있지 않습니다"라는 안내가 뜹니다. 서버를 고친 뒤 보관 목록에서 '같은 사진 재전송'을 누르면 됩니다.

## 한 팀의 진행 흐름 (약 2~3분)

1. **시작**: '네 컷 촬영하기'
2. **촬영 + 역사 미션**: 컷마다 🎲 미션이 굴러가다 정해집니다. 화면 위에 미션이, 아래에 짧은 역사 설명이 나옵니다. 1~3컷은 무작위, 4컷은 늘 '오늘의 우리답게! 자유 포즈'입니다.
3. **디자인·꾸미기**: 세 가지 디자인 중 하나를 고르고, 역사 스티커를 눌러 붙인 뒤 손가락으로 끌어 옮깁니다. 크게·작게·지우기가 됩니다. 스티커를 누르면 그 소품이나 구호의 설명이 나옵니다.
4. **접수**: 접수번호를 받습니다. 스티커는 인쇄되는 사진에 함께 들어갑니다.

| 나주역 그날처럼, 부당함에 맞서는 눈빛 | 1929년 10월 30일 나주역, 박준채는 일본인 학생의 희롱에 맞섰어요. |
| 책을 펼쳐 든 독서회 학생처럼 | 독서회는 책을 함께 읽으며 민족 의식을 키운 학생 비밀 모임이에요. |

| 어깨를 나란히, 같은 곳을 바라보며 | 광주에서 시작된 시위는 이듬해까지 전국 학생들에게 번졌어요. |
| 통학 기차를 기다리던 그날의 학생들처럼 | 광주와 나주를 오가던 통학 열차에서 사건이 시작되었어요. |
| 서로를 지켜 주듯 든든하게 | 한 사람의 항의에 많은 학생이 함께하며 운동이 커졌어요. |

문구는 `site/index.html`의 `MISSIONS` 목록에서 고칩니다.

## 역사 스티커

이모지 대신 1929년의 소품과 실제 구호로 만들었습니다. 모두 페이지 안에 그려져 있어 파일을 따로 올리지 않아도 됩니다.

- **구호 말풍선**: 조선 독립 만세 / 식민지 노예교육 철폐 / 피압박 민족 해방 만세
- **소품**: 통학 승차권(광주 ⇄ 나주), 1929·11·3 도장, 댕기, 책 꾸러미, 학생모
- **인물** (그림 PNG가 있을 때만): 박준채·박기옥·이광춘·장재성. 이름·신분 표가 붙고, 하단 문구가 `박준채와 함께한 역사네컷`으로 바뀝니다.

**행사 전에 선생님이 확인할 것**
- 인물별 학년과 역할은 공훈전자사료관이나 광주학생독립운동기념회관 자료와 대조해 주세요. 특히 박기옥·이광춘의 학년과 이광춘이 나주역에 함께 있었는지를 확인해 주세요. (`CHARACTERS` 목록)
- 구호 세 가지가 1929년 11월 시위의 격문·구호 표현과 맞는지 확인해 주세요. (`STICKER_DEFS` 목록)

## v1.7에서 바뀐 점

우리반네컷 코드에서 부스에 필요한 부분만 가져왔습니다.
- **미션 뽑기**를 '역사 미션'으로 바꿔 촬영 순서에 넣었습니다.
- **스티커 꾸미기**를 역사 소품·구호 스티커로 바꿔 넣었습니다. 끌어서 옮기기, 크게·작게, 지우기가 됩니다.
- 기기 보관 사진에도 스티커 위치가 저장되어, 새로고침 후 복구해도 그대로입니다.
- 인물은 카메라에 고정으로 겹치던 방식 대신 스티커로 원하는 자리에 놓습니다.

가져오지 않은 것: 6장 중 4장 고르기, 프레임 색상표, 이모지 스티커, 휴대폰 카메라 앱 연동. 부스 진행 속도를 늦추거나, 시대에 맞지 않거나, 크롬북 부스에는 필요 없기 때문입니다.
