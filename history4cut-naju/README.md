# 역사네컷 · 나주역 1929 (v1.6)

학생독립운동기념일(학생의 날) 행사용 네 컷 촬영 부스입니다. 이 폴더 안에 필요한 것이 모두 있습니다.

```
history4cut-naju/
├─ README.md            ← 지금 이 파일 (먼저 읽기)
├─ site/                ← 이 폴더를 통째로 촬영 사이트(HTTPS)에 올립니다
│  ├─ index.html        ← 촬영 페이지
│  └─ assets/characters/← 인물 그림 PNG 넣는 곳 (아직 비어 있음)
├─ 인물그림-만들기.md     ← 인물 그림 규격과 생성 프롬프트
├─ 서버-수정방법.md       ← Apps Script Code.gs에서 고칠 부분
├─ 검증기록.md           ← v1.6 테스트 결과
├─ v1.4-운영안내.md       ← 사진 보관·재전송 등 운영 방법 (그대로 유효)
└─ 검증기록-v1.4.md       ← v1.4 테스트 결과
```

## 배포 순서 (꼭 이 순서로)

1. **서버 먼저**: `서버-수정방법.md`대로 Code.gs의 인물 목록을 고치고 새 버전으로 배포합니다. 기존 배포를 수정하면 주소는 바뀌지 않습니다.
2. **촬영 페이지**: `site/index.html`을 기존 촬영 사이트의 같은 주소에 교체해 올립니다.
3. **인물 그림**: `인물그림-만들기.md`대로 만든 PNG를 `site/assets/characters/`에 넣어 함께 올립니다.
4. **확인**: 크롬북에서 인물 하나를 골라 한 장 접수한 뒤, 관리자 화면 '역사 인물' 칸에 이름이 찍히는지 봅니다.

서버를 고치기 전에 인물을 골라 접수하면 서버가 거절합니다. 이때 사진은 기기에 보관되고 "서버에 이 역사 인물이 등록되어 있지 않습니다"라는 안내가 뜹니다. 서버를 고친 뒤 보관 목록에서 '같은 사진 재전송'을 누르면 됩니다. '인물 없이'로 찍은 사진은 서버를 고치기 전에도 접수됩니다.

## 함께 찍는 역사 인물

| 인물 | 화면 표시 | 내용 |
|---|---|---|
| 박준채 | 광주고보 2학년 | 1929년 10월 30일 나주역에서 사촌 누나 박기옥을 희롱한 일본인 학생에게 항의 |
| 박기옥 | 광주여고보 학생 | 나주역에서 희롱을 당한 여학생 중 한 명 |
| 이광춘 | 광주여고보 학생 | 나주역에서 함께 있던 여학생 |
| 장재성 | 독서회 중앙본부 | 학생 비밀결사를 이끌며 11월 3일 이후 시위 확산을 조직 |

- **인물 그림은 아직 없습니다.** `인물그림-만들기.md`대로 그림을 만들어 `site/assets/characters/`에 넣어야 인물 선택이 나타납니다. 그림이 없는 동안에는 기존처럼 '인물 없이'만 촬영됩니다.
- 촬영 화면 오른쪽에 인물 그림이 반투명하게 겹쳐 보입니다. 학생들은 왼쪽에 서고, 네 컷 모두 같은 자리에 합성됩니다.
- 첫 컷에 `이름 · 신분` 표를 붙이고, 하단에 `복정고등학교 · 박준채와 함께한 역사네컷`이 들어갑니다.
- 결과 화면에서 접수 전이라면 인물을 바꿀 수 있습니다. 다시 찍을 필요는 없습니다.

**행사 전에 선생님이 확인할 것**: 인물별 학년과 역할은 국가보훈부 공훈전자사료관이나 광주학생독립운동기념회관 자료와 한 번 더 대조해 주세요. 특히 박기옥·이광춘의 학년과 이광춘이 나주역에 함께 있었는지를 확인해 주세요. 문구는 `site/index.html`의 `CHARACTERS` 목록에서 고칩니다.
